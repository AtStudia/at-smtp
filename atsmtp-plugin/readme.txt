Вся почта сайта отправляется через SMTP по единому файлу настроек, который лежит вне папки сайта и общий для всех сайтов хостинга. Общая для всех сайтов защита форм от спама.

== Description ==

Плагин подключается к PHPMailer (хук phpmailer_init) с максимальным приоритетом, поэтому перехватывает
все письма, отправляемые через wp_mail(): ядро WordPress, WooCommerce, Contact Form 7, WPForms, Elementor и т. д.

Параметры SMTP (сервер, порт, логин, пароль, отправитель) хранятся в отдельном файле .php или .json
за пределами сайта. На каждом сайте в «Настройки → AT SMTP» указывается путь к этому файлу.
Поменяли пароль в файле — изменение сразу действует на всех сайтах.

Перехват работает, пока плагин активен и файл настроек загружен. Чтобы отключить — деактивируйте плагин.
Если файл не загружается, письма уходят стандартным способом WordPress, а в админке показывается ошибка.

Возможности:

* Проверка файла настроек и вывод действующих параметров (пароль не показывается).
* Тестовое письмо с журналом SMTP-сессии (пароль в журнале скрыт).
* Подмена отправителя и сохранение исходного отправителя в Reply-To.
* Подстановки {site_name} и {domain} в имени и адресе отправителя.
* Индивидуальные параметры для отдельных доменов в том же файле (секция sites).
* Последняя ошибка отправки сохраняется и показывается на странице настроек.

Не перехватываются письма плагинов, которые отправляют почту в обход wp_mail()
(собственный экземпляр PHPMailer или прямой вызов mail()).

== Защита от спама ==

Код проверки, списки и настройки лежат в общем каталоге рядом с файлом настроек и используются всеми сайтами:

    /home/user/atsmtp-shared/config.php   — общий файл настроек (секция antispam)
    /home/user/atsmtp-shared/antispam/    — модуль проверки и списки по умолчанию (заменяется при обновлении)
    /home/user/atsmtp-shared/lists/       — свои списки: stopwords.txt, blacklist-ip.txt, blacklist-email.txt
    /home/user/atsmtp-shared/data/        — общий журнал и счётчики (нужно право записи для всех сайтов)

Защищаются: Elementor Pro, Contact Form 7, WPForms, Quiz And Survey Master, комментарии и отзывы WooCommerce,
регистрация WooCommerce и WordPress. Прочие формы проверяются в момент отправки письма.
Оформление заказа, вход, восстановление пароля, письма cron и залогиненных пользователей не проверяются.

Проверки: скрытое поле-ловушка, метка формы (JavaScript, время заполнения, действия пользователя),
чёрные списки IP и email, ссылки и BBCode, стоп-слова, текст без кириллицы (по желанию), лимит отправок с IP.
По желанию — невидимая Yandex SmartCaptcha.

Режимы: log — спам только записывается в журнал; block — блокируется. Начните с log и проверьте журнал
на странице настроек каждого сайта. Защиту можно выключить на отдельном сайте кнопкой на странице настроек.

Если модуль не найден или в нём ошибка, формы и письма работают как обычно, а ошибка видна в настройках.

== Installation ==

1. Распакуйте atsmtp-shared.zip из релиза на GitHub в папку вне сайтов, например /home/user/atsmtp-shared/.
2. Скопируйте config-sample.php в /home/user/atsmtp-shared/config.php и заполните.
3. Установите и активируйте плагин на каждом сайте.
4. «Настройки → AT SMTP»: укажите путь к config.php, сохраните и отправьте тестовое письмо.

Если файл не читается, проверьте права доступа и ограничение open_basedir в настройках PHP хостинга:
папка с файлом должна быть разрешена для всех сайтов.

== Обновление ==

Релизы публикуются на https://github.com/AtStudia/at-smtp/releases. Каждый релиз содержит два архива:

* at-smtp.zip — плагин. Сайты сами находят новую версию и предлагают обновиться на странице «Плагины»
  и в «Настройки → AT SMTP» (кнопка «Проверить обновления»).
* atsmtp-shared.zip — общий модуль антиспама. Обновляется вручную один раз для всех сайтов:
  распакуйте поверх общего каталога. Свои списки в lists/ и данные в data/ не затрагиваются.

Новый релиз: поднять Version в at-smtp.php (и ATSMTP_VERSION), закоммитить и отправить тег vX.Y.Z —
GitHub Actions соберёт архивы и опубликует релиз.
